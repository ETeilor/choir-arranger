# Choir Arranger 0.5

Плагин для Logic Pro (AU) и других DAW (VST3), есть и отдельное приложение. На входе аккордовая последовательность в MIDI, на выходе хоровые партии отдельными MIDI-дорожками в одном из десяти стилей: хорал Баха, православный обиход, григорианский хорал, знаменный распев, византийский напев с исоном, ренессансная полифония, contemporary, госпел, барбершоп, кинематографический эпик. Ноты можно выгрузить в MusicXML для работы с живым хором.

## Как пользоваться в Logic

1. Создайте дорожку программного инструмента и поставьте на неё Choir Arranger (AU Instruments → Teilormusic → Choir Arranger).
2. Дайте плагину аккорды одним из двух способов:
   - перетащите `.mid`-файл из Finder в окно плагина (или кнопка «Открыть MIDI»); файл узнаётся по содержимому, расширение не важно;
   - перетащите регион прямо с дорожки Logic в окно плагина (Logic отдаёт его как «обещанный файл», плагин его принимает; если на вашей версии Logic это не сработает, остаётся «Захват»);
   - положите регион с аккордами на эту же дорожку, нажмите «Захват» и запустите воспроизведение. Когда остановите транспорт, плагин заберёт сыгранное и сразу построит партии. Начало выравнивается по началу такта, в котором прозвучала первая нота.
3. Выберите стиль и сложность. Партии пересчитываются сразу, при каждом изменении.
4. Перетащите плашку партии (Soprano, Alto, ...) на дорожку с хоровой библиотекой. Саму нотную ленту тоже можно схватить мышью и утащить: это то же, что «Все партии», один мультитрековый файл, Logic разложит его по дорожкам. «Экспорт .mid» сохраняет тот же файл на диск.
5. «Прослушать» играет результат встроенным пианино или черновым хоровым «а-а» (выбор внизу слева, «Звук прослушивания»). Те же ноты плагин отдаёт на свой MIDI-выход. Слева от нотной ленты клавиатура: при прослушивании на ней подсвечиваются звучащие клавиши цветом партии.
6. «Ноты (MusicXML)» сохраняет партитуру для MuseScore, Sibelius, Dorico, Finale: по нотоносцу на партию, ключи по голосам (теноры в скрипичном с восьмёркой), знаки при ключе по найденной тональности или ладу. Плашку «Ноты» можно перетащить прямо в Finder или в окно нотного редактора.

Вход, стиль и все ручки сохраняются в проекте Logic.

## Ручки

- **Стиль:** десять стилей (см. выше). Барбершоп ведёт мелодию во втором голосе (Lead), contemporary делит партии на divisi, византийский напев идёт с исоном, эпик строится на остинато.
- **Сложность** 0–10, общая; у хорала и обихода ещё четыре ручки S, A, T, B. Крайнее левое положение голосовой ручки (`=`) означает «как общая».
- **Обиход и знаменный распев:** октависты пятой дорожкой.
- **Знаменный и византийский:** что делать с аккордами вне лада.
- **Григорианика:** фактура (унисон, органум в кварту, органум в квинту), что делать с аккордами вне лада (подменять ладовым или пропускать), смешанный хор (сопрано и альты октавой выше).

## Сборка на Mac

Нужны Xcode (с Command Line Tools) и CMake 3.22+ (`brew install cmake`). JUCE 8.0.4 скачается сам.

```
cmake -S . -B build -G Xcode
cmake --build build --config Release --target ChoirArranger_AU ChoirArranger_VST3 ChoirArranger_Standalone
```

Готовые файлы:

- `build/ChoirArranger_artefacts/Release/AU/Choir Arranger.component` → скопировать в `~/Library/Audio/Plug-Ins/Components/`
- `build/ChoirArranger_artefacts/Release/VST3/Choir Arranger.vst3` → в `~/Library/Audio/Plug-Ins/VST3/`
- `build/ChoirArranger_artefacts/Release/Standalone/Choir Arranger.app`

Проверка AU тем же валидатором, что запускает Logic: `auval -v aumu Chor Tlrm`. Если Logic не видит плагин, перезапустите его или сбросьте кэш: `killall -9 AudioComponentRegistrar`.

Без Mac под рукой можно собрать в GitHub: в репозитории лежит `.github/workflows/build-macos.yml`, он собирает универсальные AU и VST3 (Apple Silicon и Intel), прогоняет `auval` и выкладывает результат в артефакты сборки. Скачанный из интернета плагин macOS пометит карантином; снимается так: `xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/Choir\ Arranger.component`. Сборка не подписана сертификатом Apple, для своих машин это не нужно, для продажи понадобится подпись и нотаризация.

## Устройство

- `core/` движок на C++17 без зависимостей: анализ входа, перевод гармонии, поиск голосоведения (Витерби), ручка сложности, украшения, обиход, григорианика, проверка правил, чтение и запись MIDI.
- `plugin/` оболочка JUCE: процессор (захват с транспорта, состояние, прослушивание) и интерфейс (пианоролл, плашки для перетаскивания).
- `cli/` консольная версия движка с теми же ключами, что у прототипа на Python.
- `tests/compare_golden.py` сравнивает C++ с прототипом: 580 случаев (20 тестовых файлов × три стиля × уровни сложности × фактуры), совпадение нота в ноту.
- `tests/plugin_test.cpp` проверяет плагин целиком: загрузку файла, захват с имитированного транспорта, сохранение в проекте, файлы для перетаскивания, прослушивание и снимки интерфейса.
